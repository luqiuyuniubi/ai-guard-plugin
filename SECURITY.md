# Security policy

AI Guard is an experimental portfolio project, not a security guarantee.
Use synthetic data for demonstrations. Do not deploy the demo authentication
or assume regex detection prevents all prompt injection and data poisoning.

If you discover a vulnerability, use the repository's GitHub private
vulnerability reporting feature when available. Avoid publishing credentials,
personal data or exploitable details in public issues. If private reporting
is unavailable, open an issue requesting a private contact without including
sensitive details.

Reports should describe the affected version, trust boundary, minimal
synthetic reproduction and expected versus actual behavior.
